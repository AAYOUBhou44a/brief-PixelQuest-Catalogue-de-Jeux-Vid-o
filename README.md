# 🎮 Catalogue des jeux de video

## 📝 Description
Ce projet est une petite application web qui permet d’afficher et de rechercher des jeux vidéo en utilisant l’API **RAWG**.  
L’utilisateur peut aussi ajouter ses jeux préférés dans les favoris, qui sont gardés grâce au **localStorage**.  
Le site est **responsive** et déployé sur **GitHub Pages**.

---

## ⚙️ Fonctionnalités
- Affichage dynamique des jeux avec **fetch()**
- Recherche d’un jeu par **nom**
- Ajout / suppression d’un jeu dans les **favoris**
- Sauvegarde des favoris dans le **localStorage**
- Page “**Mes Favoris**” pour voir les jeux enregistrés
- **Loader** affiché pendant le chargement
- Design **responsive** (mobile et ordinateur)
- **Déploiement** sur GitHub Pages

---

## 🧠 Outils utilisés
- **HTML**
- **Tailwind Css**
- **JavaScript**
- **API RAWG**
